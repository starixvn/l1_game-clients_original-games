## 安裝問題排解
如果遇到  sg/sg-game-client 安裝或打包問題

類似下列錯誤
```
npm ERR! 404 Not Found - GET https://registry.npmjs.org/@sg%2fsg-game-client - Not found
npm ERR! 404 
npm ERR! 404  '@sg/sg-game-client@1.0.6' is not in this registry.
```

因為 sg/sg-game-client 是越南 Team 提供的內部套件，請嘗試
1. 修改 registry  
```
npm set registry http://npm.lumigame.com
```

2. 使用 yarn 安裝，路徑一樣是 /seal-monorepo
```
yarn install
```

如果安裝 / 打包 成功沒問題之後，記得還原 registry  
3. 還原 npm registry  
```
npm set registry https://registry.npmjs.org/
```

## Release
目前會將打包好的檔案放到另一個對外專案: seal-components，提供 NF 使用 npm package 引用

seal-components branch
- npm-release: 內部測試用

### 更新步驟

1. 確認已 clone seal components
    https://git.owgps.net/seal/seal-components

2. 執行以下指令，會自動將 artifacts 更新到 seal components branch: `npm-release`
  ```
  npx nx run seal-components:release 
  ```
  若想自己打版號，更新完版號後執行 build 和 publish
  ```
  // 1. 打版號
  // 自動打版號
  npx nx run seal-components:version
  // 只更新最右邊的版號
  npx nx run seal-components:version:patch
  // 自訂義版號後綴 (適合要測試上版，但還未確認要發布的情況)
  npx nx run seal-components:version --prerelease ${自訂後綴}

  // 2. build
  npx nx run seal-components:build

  // 3. 發布到 seal-components 專案
  npx nx run seal-components:publish
  ```
3. 內部測試沒問題後，到 seal-components 專案手動打一個版號: `npm-release-1.2.0`，版號請和 package.json 相同

4. 通知 NF 取用

## Running tasks

To execute tasks with Nx use the following syntax:

```
nx <target> <project> <...options>
```

You can also run multiple targets:

```
nx run-many -t <target1> <target2>
```

..or add `-p` to filter specific projects

```
nx run-many -t <target1> <target2> -p <proj1> <proj2>
```

Targets can be defined in the `package.json` or `projects.json`. Learn more [in the docs](https://nx.dev/features/run-tasks).
