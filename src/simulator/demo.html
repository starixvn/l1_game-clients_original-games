🔗 Connection Management Simulator Demo

📋 Overview

This demo shows how to integrate and test the Connection Management Simulator in your application. The simulator helps you test connection management features like load balancing, throttling, and fallback mechanisms.

🚀 Quick Start

  1. Open your browser's developer console (F12)
  2. Use the test buttons below to simulate different scenarios
  3. Monitor the connection metrics in real-time
  4. Check the console for detailed logs

💻 Integration Code

Here's how to integrate the simulator into your React application:

// 1. Import the simulator components import { ConnectionControlSimulatorWrapper, useConnectionSimulator } from './simulator'; import { useSSOSimulator } from './_shared/components/sso-control-simulator'; // 2. Use the hooks in your component const YourApp = () => { const connectionSimulator = useConnectionSimulator(); const ssoSimulator = useSSOSimulator(); return ( {/* Your existing app content */} ); };
// 3. Programmatic control const connectionSimulator = useConnectionSimulator(); // Simulate high load connectionSimulator.simulateLoadLevel('high'); // Set connection limit connectionSimulator.setConnectionLimit(10); // Enable throttling connectionSimulator.setThrottlingLevel('moderate'); // Enable polling fallback connectionSimulator.enablePollingFallback(true);

📝 Console Commands

You can also run these commands directly in the browser console:

// Get the simulator instance const simulator = window.connectionSimulator; // Quick tests window.ConnectionSimulatorTests.quickLoadTest(simulator); window.ConnectionSimulatorTests.connectionLimitTest(simulator); window.ConnectionSimulatorTests.throttlingTest(simulator); window.ConnectionSimulatorTests.runAllTests(simulator); // Manual control simulator.simulateLoadLevel('high'); simulator.setConnectionLimit(5); simulator.setThrottlingLevel('aggressive'); simulator.forceDisconnect();
